# BITE Project

BITE Project è una piattaforma editoriale e operativa per viaggi in barca a vela: sito pubblico bilingue, logbook geolocalizzato, booking voyage, newsletter, mail admin e layer semantico pubblico.

## Stack attuale
- Frontend: Vite, React, TypeScript, Tailwind, shadcn/ui.
- Backend dati e funzioni: Supabase Postgres, Auth, Storage, Edge Functions.
- Hosting e API server-side: Vercel.
- Email: Resend per invio/ricezione e webhook, con storico e preferenze su Supabase.

## Nota storica
Il progetto è nato su Lovable Cloud ed è poi stato migrato fuori da Lovable. Lovable non è più un servizio operativo dello stack.
